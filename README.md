## 📦 INSTALLATION

### Step 1 — Upload Files
Upload all bot files to your hosting server. Make sure `index.js` is at the **root level**.

### Step 2 — Install Dependencies
```bash
npm install
```

### Step 3 — Configure the Bot
Open `config.js` and set your details:

```js
module.exports = {
    botName:     'MAHNGUELOH-MD',
    ownerName:   'MAHNGUELOH',
    ownerNumber: '254732223354',  // ← Your WhatsApp number (no + sign)
    prefix:      '.',
    mode:        'public',        // 'public' or 'private'
}
```

### Step 4 — Start the Bot
```bash
node index.js
```

## 🔑 PAIRING YOUR WHATSAPP

When you start the bot for the first time, a pairing code will appear in the console:

```
════════════════════════════════════════
=  PAIRING CODE: XXXX-XXXX            =
════════════════════════════════════════

STEPS:
  1. Open WhatsApp on your phone
  2. Menu (3 dots) → Linked Devices
  3. Link a Device
  4. Link with phone number instead
  5. Type your number
  6. Type the pairing code
```

> ⚠️ **Important:** The number you type in step 5 must EXACTLY match the `ownerNumber` in `config.js`

> ⏰ **Note:** The code expires in 60 seconds. If it expires, delete the `auth_info` folder and restart.

## 🔄 TROUBLESHOOTING

<details>
<summary><b>❌ "Couldn't link device" error</b></summary>

This means the phone number you entered in WhatsApp doesn't match `ownerNumber` in config.js.

**Fix:**
1. Check `ownerNumber` in `config.js` (no + sign, no spaces)
2. Delete the `auth_info` folder
3. Restart the bot
4. Enter the **exact same number** shown in the console into WhatsApp

</details>

<details>
<summary><b>❌ Bot connects but commands don't work</b></summary>

1. Make sure files are at **root level** (not inside a subfolder)
2. Run `npm install` fresh
3. Check that `prefix` in config.js matches what you're typing (default: `.`)
4. Try `.ping` first — if it responds, bot is working

</details>

<details>
<summary><b>❌ Downloads failing</b></summary>

Run `pip3 install yt-dlp` in your server console. This installs the download engine.

</details>

<details>
<summary><b>❌ Bot keeps getting logged out</b></summary>

1. Turn OFF `alwaysonline` and `autotype`
2. Run `.bancheck` to see risky settings
3. Don't use `.tagall` too frequently
4. Avoid sending many messages rapidly

</details>
