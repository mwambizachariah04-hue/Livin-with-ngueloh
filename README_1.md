## 🚀 INSTALLATION

```bash
# 1. Clone the repository
git clone https://github.com/yourusername/MAHNGUELOH-MD.git

# 2. Enter the bot folder
cd MAHNGUELOH-MD/bot

# 3. Install dependencies
npm install

# 4. Edit your number in config.js
nano config.js

# 5. Start the bot
node index.js
```

## 🔑 PAIR CODE / SESSION LINKING

<div align="center">

[![PAIR CODE](https://img.shields.io/badge/🔑_PAIR_CODE-Get_Device_Session-FF6B35?style=for-the-badge)](https://whatsapp.com/channel/0029Vb7B7pS6rsQksHVznm0j)

</div>

1. Run `node index.js`
2. Enter your phone number with country code (e.g. `254712345678`)
3. An **8-digit pairing code** appears in your terminal
4. On WhatsApp → **⋮ Menu → Linked Devices → Link a Device → Link with phone number**
5. Enter the pairing code → bot connects ✅

### 🤖 GitHub Actions — Free CI/CD Workflow

```yaml
name: MAHNGUELOH-MD CI

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: 📥 Checkout
        uses: actions/checkout@v3

      - name: 🟢 Setup Node.js 20
        uses: actions/setup-node@v3
        with:
          node-version: '20'

      - name: 📦 Install dependencies
        run: cd bot && npm install

      - name: ✅ Check syntax
        run: |
          cd bot
          node --check index.js
          node --check handler.js

      - name: 🤖 Start bot (background)
        run: cd bot && node index.js &
```
